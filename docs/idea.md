## 주제
모의주식 및 주식 예측 시스템( web )  
## 기능제안
### 유저
```
1. 회원가입
2. 로그인
3. 초기자금 제공, 충전기능(가짜돈)
4. 보유한 주식 목록과 보유 자산관리(수익률) 기능  
```
### 주식거래
```
1. 실시간 주가정보제공
2. 매수 및 매도
3. 증시 현황(실 주식은 api / 모의주식은 구현)
```
### 정보제공
```
1. 종목 정보
2. 기업 정보 및 뉴스(api 이용)
```
### 파이썬
```
1. 주식 가격 예측 ( regression_model 사용 )
2. 1번을 기반으로 주식 추천 알고리즘 구현
```
